# KUROI Studio

ブラウザだけで動くアバター＆3D モデリングスタジオです。パラメトリックにキャラクターを作り、ポーズ・表情・揺れ物を付けて、**17 種類のファイル形式**に書き出せます。インストール不要、サーバー不要で、処理はすべてローカル（ブラウザ内）で完結します。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に静的サイトを出力（どこにでもホスティング可）
npm test         # エクスポーター / リグのユニットテスト
```

## 主な機能

### アバター作成
- **50 以上のパラメータ**: 身長・頭身・肩幅・バスト・ウエスト・脚の長さ、目の大きさ・つり目/たれ目・瞳・眉・口・あご・頬 など
- **髪型** 8 種（ロング / ボブ / ショート / ポニーテール / ツインテール / お団子 / ツンツン / なし）+ **前髪** 4 種 + アホ毛、2 色グラデーション
- **耳**: 人間 / エルフ / ネコミミ
- **衣装** 6 種（セーラー服 / カジュアル / ワンピース / パーカー / スーツ / インナー）、丈・袖の長さ調整、靴 3 種
- プリセット（スタンダード / クール / ちびキャラ / 少年 / エルフ）と**ランダム生成**
- トゥーンシェーディング + 反転ハル方式のアウトライン

### リグ・表情・物理
- **VRM 準拠のヒューマノイドボーン** 24 本（hips〜toes・目）
- 骨からの距離に基づく**滑らかなスキンウェイト**の自動生成
- **VRM プリセット表情 13 種**（喜怒哀楽・驚き・あいうえお・まばたき・ウィンク）をモーフターゲットとして生成
- 自動まばたき、視線用の目ボーン
- **SpringBone 揺れ物**（ポニーテール・ツインテール・ロングヘア）とコライダー、風

### ポーズ & アニメーション
- ポーズプリセット 10 種、**ボーン直接編集モード**（クリック → 回転ギズモ / 数値スライダー）
- 手続き生成アニメーション 6 種（待機 / 手を振る / 歩く / ダンス / お辞儀 / ジャンプ）
- BVH モーションの読み込み・書き出し

### モデリング
- プリミティブ 12 種（立方体・球・円柱・円錐・カプセル・トーラス・結び目・平面・多面体・リング・星・ハート）とパラメータ編集
- 複製 / ミラー複製 / 直線配列 / 円形配列 / 床に置く / 原点を中心へ / スムーズ・フラット
- マテリアルエディタ: トゥーン / PBR スタンダード / PBR フィジカル（クリアコート・透過・IOR・虹彩・シーン）/ アンリット、テクスチャ割り当て
- アンドゥ / リドゥ（変形・形状・マテリアル・アバター・ポーズ）

### エクスポート（17 形式）

| 分類 | 形式 | 内容 |
| --- | --- | --- |
| VTuber / アバター | **VRM 1.0** | ヒューマノイド・表情・視線・SpringBone・MToon・サムネイル・ライセンス情報 |
| | **VRM 0.x** | BlendShape・SecondaryAnimation・MToon materialProperties（-Z 正面に自動変換） |
| 汎用 3D | **glTF バイナリ (.glb)** | スキンメッシュ・モーフ・アニメーション・テクスチャ |
| | **glTF (.gltf)** | JSON 版 |
| | **USDZ** | iPhone の AR Quick Look でそのまま表示 |
| | **three.js JSON** | ObjectLoader 形式 |
| DCC ツール | **FBX 7.4 バイナリ** | 自前のバイナリライター。メッシュ・法線・UV・頂点カラー・マテリアル |
| | **OBJ + MTL (ZIP)** | マテリアル・テクスチャ PNG 同梱 |
| | **Collada (.dae)** | |
| | **X3D** | |
| | **PLY** | マテリアル色を頂点カラーに焼き込み |
| 3D プリント | **STL バイナリ / ASCII** | mm・Z-up・接地への自動変換オプション |
| | **3MF** | マテリアル色付き |
| モーション | **BVH** | 再生中のアニメーションを 30fps で |
| 画像・動画 | **PNG** | 2 倍解像度・背景透過 |
| | **WebM** | 360° ターンテーブル動画 |

FBX / OBJ / STL / PLY / DAE / X3D / 3MF / USDZ は、現在のポーズ・表情・スキニングをワールド座標に焼き込んで出力します（T ポーズ出力オプションあり）。

### インポート
GLB / glTF / VRM / FBX / OBJ / STL / PLY / DAE / 3MF / USDZ / three.js JSON / BVH / 画像（下絵）。ドラッグ＆ドロップ対応。cm 単位の FBX などは自動でスケール調整して接地します。

### プロジェクト
`.kuroi` 形式で保存・読み込み。作業内容はブラウザに自動保存されます。

## 検証

- `npm test`: zip/CRC、GLB 再構築、FBX の三.js FBXLoader による読み戻し、STL/PLY/OBJ/DAE/X3D/3MF の構造、全プリセットのリグ整合性（ボーン・モーフ・ウェイト正規化）、VRM 1.0 / 0.x 拡張の内容、BVH
- 書き出した GLB / VRM 1.0 / VRM 0.x は Khronos glTF-Validator で **エラー 0**、`@pixiv/three-vrm` で読み込み可能（ヒューマノイド 24 ボーン・表情 13 種・SpringBone・MToon）なことを確認済み

## 構成

```
src/
  avatar/      アバター生成（ジオメトリ・リグ・表情・髪・衣装）、揺れ物、アニメーション
  core/        ビューポート（Studio）、アンドゥ履歴
  io/          エクスポーター（VRM・FBX・各種ライター・ZIP・GLB）、インポーター、プロジェクト
  modeling/    プリミティブ
  ui/          UI（パネル・エクスポートダイアログ・ポーズ編集）
tests/         Vitest
```

技術: TypeScript / Vite / three.js。外部依存は three.js のみ（FBX・ZIP・3MF・Collada・X3D・PLY・STL・BVH・VRM の書き出しは自前実装）。

## 制限事項

- FBX は現在静的メッシュ（ポーズ焼き込み）での出力です。ボーン付きで使う場合は VRM / glTF を推奨します。
- X3D と OBJ の ZIP は読み込みに対応していません（書き出しのみ）。
- WebM 録画は MediaRecorder 対応ブラウザ（Chrome / Edge / Firefox）が必要です。
